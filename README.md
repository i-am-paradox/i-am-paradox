### 📌 Executive Overview

> **I am an Offensive Security Researcher and Systems Architect with an academic foundation in applied mathematics.**  
> My work spans the complete lifecycle of secure computing: from discovering edge-case invariant violations and protocol flaws through rigorous reverse engineering, to building memory-safe, deterministic, high-throughput distributed infrastructure in **Rust**, **C++**, and **Go**.  
>
> I approach computing with a foundational axiom: *code is applied discrete mathematics — if the mathematical model permits an unsafe state transition, no firewall can prevent the exploit.*
