## About

Security researcher and full-stack engineer from India. I spend most of my time in **offensive security** — web/API exploitation, reconnaissance automation, and mobile app analysis — and I build production software when I'm not breaking it: a published Android app, an end-to-end encrypted messenger, and Rust/Python security tooling.

**Currently:** hunting on HackerOne, building automated recon pipelines, and sharpening mobile app analysis skills.
